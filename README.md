# nara.sofwah.my

GitHub Pages untuk **NARA HR** (The People Management Platform) · Sofwah Arabiata (M) Sdn. Bhd.

- `/hr/` — app web (PWA), dibina daripada repo peribadi `sofwah-nara` (cawangan `nara-hr-app`) dengan `node tools/build-pwa.js <portal>/hr <URL /exec>`
- `/hr/privacy.html` — Dasar Privasi (URL untuk App Store & Google Play)
- `/hr/support.html` — Bantuan / Support URL; `#delete` = arahan padam akaun

Tiada data peribadi dalam repo ini. Semua data berada dalam Google Workspace Sofwah (Apps Script).
